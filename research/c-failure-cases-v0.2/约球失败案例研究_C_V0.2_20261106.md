# 国内球类线下社交/约球 失败案例研究（C 块）V0.2

- 状态：**DRAFT｜合并研究稿，待审；非经营决策、非执行授权、非对外材料。**
- 研究及本轮重测日期：**2026-11-06（北京时间，Asia/Shanghai，UTC+8）**。
- 正式案例取两研究线并集：动起来、乐奇足球、羽乐圈。**两例历史停服/解散、一例经营危机与转型，不是“三家已倒闭”。**

## 0. 一页结论（结论先行）

### 三个案例，各一句失败解释

1. **动起来：**2016 年 3 月已有团队解散、App 停服及中国区下架报道；虽曾自述有场馆分成、赛事赞助收入，但不足以确定模式经济性还是执行/治理问题主导致死，欠薪仍须标作员工指控。[央广经营采访](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)；[同期停服报道](https://news.mydrivers.com/1/474/474392.htm)
2. **乐奇足球：**补贴未沉淀稳固供给关系，停补后交易下滑，叠加激励风控与活动持续性问题，旧模式在 2016—2017 年陷入危机并转向线下；**不称其已倒闭**。[界面多方采访](https://www.jiemian.com/article/992019.html)
3. **羽乐圈：**员工与创始人采访支持资金短缺、融资依赖和团队连续性失守，2016 年 11 月解散；“投资尾款未到”和“系统被破坏”的具体责任未独立证实，不能判成球会社群或工具需求失败。[铅笔道多方采访](https://www.pencilnews.cn/p/13770.html)

### 四条基本盘，验证到哪里

| 基本盘 | 合并结论 |
|---|---|
| 单价高 | **未验证。**没有可用的人均实付、社交服务溢价数据；球队整单和赛事服务收入不能代替网球 C 端高客单。 |
| 频次低 | **弱支持，主要是评论和相对频次判断。**缺打球、找新同伴、打开 App、平台交易各自的行为数据；羽乐圈日常球会与赛事也不能混算。 |
| 强地域（3 公里内） | **本地供给和组织重要有方向性支持；3 公里完全未验证。**城市合伙人、附近搜索不是消费者距离阈值的实证。 |
| 强社交 | **有找同伴、球队/球会组织的需求线索；强平台社交未验证。**关系强度、关系留存、付费社交及社群盈利都缺数据。 |

### 四个判断，得到多少支持

| 判断 | 支持程度与边界 |
|---|---|
| 平台模式难 | **有条件、中等支持。**主要约束跨城扩张、补贴依赖、供给关系薄弱和复杂线下履约，不证明所有平台必败。 |
| 社群模式可行 | **只支持组织工作流有价值；盈利可行未验证。**平台失败不能反证小社群一定成功。 |
| 工具收费可行 | **未验证。**场馆分成、赛事服务收入、合伙人入伙费，均不能冒充工具订阅、续费或高毛利。 |
| 抽成模式危险 | **条件性风险支持，未证实“因抽成而死”。**乐奇显示薄利与补贴/履约负担的风险；动起来只确认做过分成，羽乐圈未核实抽成机制。 |

上述两表是下文逐案证据的研究判断，不是新增事实。[动点评论与功能](https://cn.technode.com/post/2016-03-28/whatimpressme/)；[乐奇当年采访](https://www.36dianping.com/info/18238.html)；[羽乐圈历史功能](https://www.cr173.com/soft/213224.html)

### 最大缺口与当前落点

**最大缺口不是再凑一个死亡名字，而是缺纯网球、单城/小半径、无补贴条件下的真实成局、复访、支付和贡献利润数据，以及盈利社群/付费工具的成功对照。**三个案例都是较早期混合业务，不能替常州项目通过或否决商业模式；可搭呀等仅列待核线索，不补足样本数。

**“不做平台”不等于内容、社群或工具收费已经跑通。**本稿仅研究，常州网球阶段一仍为 **¥0、零收款**；未发群、未联系任何人，也不批准收费、办局、投放、招募或对外发布。

### 1.3 事实、推断与未验证

事实须附链接，并保留“谁说的”；推断采用“假设→证据→结论”。本文的“做对”仅指合理的产品切口或服务动作，不表示已盈利。未验证不是反驳；下载页仍在不是存活，停止更新也不是死亡。当前研究无任何收费或行动授权效力。

### 2.3 死前做对了什么

1. **人和场一并处理。**伙伴、活动、预付款与球友社区都在同一服务链路中，不是只有库存列表；实际成局率仍未知。[动点](https://cn.technode.com/post/2016-03-28/whatimpressme/)
2. **做过线下履约衔接。**运营/客服电话确认预订送达，回应“线上下单、线下不认”的流程风险；不代表这种人工服务成本可承受。[2015 年转载](http://www.sczw.com/webnews/3744.html)
3. **明确触及收入与社群机制。**同期本人谈过分成、赛事赞助及培养交往习惯；“有收入”和“识别社群重要”均不等于商业留存已经跑通。[央广](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)

### 2.4 模式还是执行：假设 → 证据 → 结论

| 假设 | 证据 | 结论 |
|---|---|---|

**总评：模式经济性可能脆弱，停服伴随组织争议；现有材料不能判清模式与执行的主次，更不能补造资金链。**

### 2.6 四个商业判断

- **平台模式难：支持风险，不证明必死。**扩张、有限盈利自述与停服相接，但没有完整财务。[央广](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)；[快科技](https://news.mydrivers.com/1/474/474392.htm)
- **社群模式可行：只见组织基础，盈利未验证。**原有群与熟人也可能替代平台。[动点](https://cn.technode.com/post/2016-03-28/whatimpressme/)
- **工具收费可行：未验证。**分成和赞助不是订阅/许可证收费。[央广](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)
- **抽成模式危险：风险命题，不是致死结论。**确认做过分成，未知费率、绕单和订单净贡献。[央广](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)

## 3. 正式案例二：乐奇足球——补贴型订场约战受挫，组织活动中断后转向线下

### 3.3 受挫之前做对了什么

- **找到球队队长这一真实组织节点。**报道记载地推人员在球场教队长使用 App、组织赛事和活动，甚至在人手不足时陪练。它不是只用线上流量等待陌生人自然成局；但人工成本未披露。[36氪转载](https://www.36dianping.com/info/18238.html)
- **把实际成交放在产品中心。**当年两项核心功能是约球和订场，且已有球队订单。交易额只能证明有人使用，不能证明佣金覆盖履约成本。[36氪转载](https://www.36dianping.com/info/18238.html)
- **识别了本地关系与运营不可省略。**城市合伙人负责球场签约、当地推广和活动，确实形成多城覆盖；可复制的是协作框架，不代表单城经济性已经验证。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)
- **尝试从交易扩展到组织服务。**三角赛、城市联赛是实际尝试；员工称初期有成效，但之后中断，不能包装成已跑通的社群模式。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)

### 3.4 死因推理：假设 → 证据 → 结论

| 假设 | 证据 | 结论与分类 |
|---|---|---|
| H1：补贴购买交易，但没有买到独占关系。 | 合伙人、球场、用户多方补贴；员工称停补后交易下降，合伙人称球场转与其他补贴平台合作。CEO 自述需纠正“低毛利、大规模”路径。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html) | **模式问题，支持度中等偏强（定性）。**证据支持补贴退出时脆弱，不支持计算确切流失率或断言每笔亏损。 |
| H2：平台创造的增量不足，场馆供给方未必需要 OTA。 | 2015 年记者已提出黄金时段场地紧缺的质疑；2017 年追访中，同业和业内人士指出场馆不愁客户、纯导流价值弱。[36氪转载](https://www.36dianping.com/info/18238.html)；[界面新闻，2017-01-04](https://www.jiemian.com/article/1050146.html) | **模式问题，中等支持。**适用于当时相应市场/时段，不能泛化所有城市、所有空闲时段都供不应求。 |
| H3：扩张激励和风控失配，放大现金消耗。 | 城市合伙人不属于员工、协作关系松散；刷单现象有当事人陈述与 CEO 对系统漏洞的承认。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html) | **执行/治理问题，中等支持。**无法量化刷单占总损失比例；并非有合伙人制度就必然失败。 |
| H4：通过赛事、社交服务转型，就能补足收入。 | 赛事初期效果来自员工描述，随后中断；2018 年回顾亦称“三角赛”不了了之；同时 CEO 声称转线下场馆有现金流。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)；[投资界回顾](https://news.pedaily.cn/201806/432518.shtml) | **未被验证；有反向风险信号。**只能说这一团队的活动转型没有持续，不是“小社群一定赚不到钱”。 |

**归因判定：模式与执行叠加，不能二选一。**模式层面是补贴驱动、低毛利且缺乏稳固供给关系；执行层面是激励/风控和活动方向持续性问题。现金紧张、欠薪与收缩是危机表现；不能反向据此补出精确资金链或把全部责任归某个人。

### 3.6 推到四个商业判断

- **平台模式难：有条件支持，强于动起来。**补贴退出后的交易下滑、供给关系松散与模式修正有同案报道；只约束这种跨城低毛利撮合平台。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)
- **社群模式可行：未验证，并提示“活动≠利润”。**有本地组织和短期活动效果，但没有持续盈利证据；活动中断也不能反驳所有小型社群。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)
- **工具收费可行：未验证。**本案不是已核实的 SaaS 订阅商业模式；合伙人入伙费不能拿来充当组织工具的付费意愿。
- **抽成模式危险：条件性支持，不构成全面否定。**当撮合收入/毛利薄，还承担补贴和人工履约时，交易额增长不等于造血。没有佣金率及订单成本，不能声称“佣金必定低于成本”。[界面新闻，2016-12-02](https://www.jiemian.com/article/992019.html)；[界面新闻，2017-01-04](https://www.jiemian.com/article/1050146.html)

### 4.3 死前做对了什么

1. **围绕会长持续劳动做工具。**消息推送、报名、记账与查看权限都是历史文案中的明确工作流，不只是“附近的人”。功能存在不代表使用量或节省工时已测量。[历史功能](https://www.cr173.com/soft/213224.html)
2. **处理复杂赛事的多角色协同。**报名、抽签、名单、裁判管理、记分和实时赛况指向清晰的组织任务；设计服务方也保存了这些流程，但宣传页不是独立效果评估。[产品页](https://www.cr173.com/soft/213224.html)；[设计方案例](https://www.g-day.net/m_case-2-13.html)
3. **有明确的收费服务对象线索。**记者记载主要通过服务赛事获取收入，说明不只是在等待流量广告；未知谁付费、服务毛利与续用。[收入报道](https://www.pencilnews.cn/p/13770.html)

### 4.4 模式还是执行：假设 → 证据 → 结论

| 假设 | 证据 | 结论 |
|---|---|---|
| H1：融资依赖与现金管理失守导致团队不能持续运转。 | 创始人承认当时缺钱；欠薪、裁员、解散的员工叙述与之衔接；尾款不到为创始人解释。[铅笔道](https://www.pencilnews.cn/p/13770.html) | **执行/融资依赖的近因支持较强。**可说资金与团队连续性失守，不能独立裁定某投资方责任或把未到账全当外部偶然。 |
| H2：免费球友平台＋赛事服务收入，不能承载研发和人员。 | 免费功能与赛事收入并存，后来缺钱；没有收入结构、人员成本、赛事毛利和回款周期。[产品页](https://www.cr173.com/soft/213224.html)；[采访](https://www.pencilnews.cn/p/13770.html) | **模式经济性有疑问、未被验证为根因。**不能排除回款、扩张与管理等因素，更不能判免费模式必败。 |
| H3：攻击/代码破坏先毁掉系统，才导致失败。 | 创始人与员工对破坏或失维护各执一词，时间线上现金/人员问题先出现。[铅笔道](https://www.pencilnews.cn/p/13770.html) | **不是已证实根因。**最多称技术连续性也失守，可能是资金与人员流失的结果，不能补造攻击者。 |
| H4：球会工具没人要、卖不动，所以关门。 | 有工具文案与赛事收入，但无工具付费、续费、活跃球会及组织者利润数据。[产品页](https://www.cr173.com/soft/213224.html)；[采访](https://www.pencilnews.cn/p/13770.html) | **无法检验。**公司死亡不能证明工具无需求，也不能替工具收费做成功背书。 |

**总评：现金流、融资依赖和团队执行连续性的证据明显强于“球会社群模式必败”的证据；模式能否赚钱仍未证实。**

### 5.3 四个判断的最终范围

- **平台模式难——有条件、中等支持。**乐奇有补贴退出后交易下滑与模式修正的同案采访链；其余两例提示收入、融资与组织连续性风险。但均非完整财务实验，不能推出所有平台失败。[乐奇](https://www.jiemian.com/article/992019.html)；[动起来](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)；[羽乐圈](https://www.pencilnews.cn/p/13770.html)
- **社群模式可行——组织工作流有价值线索，盈利未验证。**找同伴、报名、费用管理有明确切口，但无主理人净收入、会员续费或独立球会损益。不能从“不做平台”直接跳到“社群可赚钱”。[活动与群聊评论](https://cn.technode.com/post/2016-03-28/whatimpressme/)；[球会功能](https://www.cr173.com/soft/213224.html)
- **工具收费可行——未验证。**免费工具被使用、服务赛事收费、合伙人入伙费及分成，都不是工具订阅证据；没有许可证收入、续费和服务成本分离数据。[动起来收入](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)；[羽乐圈收入](https://www.pencilnews.cn/p/13770.html)
- **抽成模式危险——条件性风险支持，不是致死因果。**撮合收入薄而补贴、人工履约、获客负担高时危险；本次缺费率和单笔贡献账。动起来做过分成只是共现，羽乐圈抽成未核实。[乐奇模式修正](https://www.jiemian.com/article/992019.html)；[动起来](http://www.cnr.cn/jingji/gs/20150722/t20150722_519282933.shtml)

**对常州项目的研究提醒：**内容互动、进群、到场、重复参与、愿意付费与真实净贡献是不同层级证据，不得互相替代。这里不设置新 KPI、不启动新增实验，阶段一 ¥0、零收款及原审批闸门不变。

## 8. 方法、来源与本轮全部链接核验

### 8.1 方法与局限

1. 先确认约人/组织场景和退出/危机证据，再回查业务与收入。事实、当事人陈述、商业文案、行业观点和研究推断分开。
2. 两稿作为检索线索，不把另一研究者的“已核验”当本轮验证；对其引用与关键结论重新打开原页。没有采用搜索自动总结作为死亡或因果依据。
3. **本轮全部 21 个不同外部 URL 均重测：18 个正文可读、3 个访问受限；未遇 404，无需删除 404 链接。**若后续出现 404，应去掉链接及无替代来源的硬主张，而不是只删链接保留断言。
4. WebFetch 可读只表示返回了题名匹配正文，工具不逐页暴露状态码，不伪写“全部 HTTP 200”。403、超时与 5xx 均保留并注明访问受限，不将故障当页面/公司不存在。
5. 同期原创采访优先，但创始人自述不是审计；同源转载不增加证据独立性。下载站更新日不证明后台存活；商店评论可能片面或过时；设计页具有商业宣传偏差。
6. 没有安装旧产品、注册、联系任何人、核对银行流水、获取工商原档或司法原件。没有通过账号或私人数据库进行调查。
7. 样本是有目的选择、存在媒体/冲突报道偏差，且大多距今较久；无成功对照。不能计算失败率、常州成功概率或市场规模。
8. 下一轮若要升级商业判断，缺的是价格/距离/频次/留存/净贡献的行为证据和成功对照，不是更多无证“最新版下载”。**此段不授权启动下一轮或任何线下业务。**
